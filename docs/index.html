Methodology

Research approach and validation rigor.

Simulation Framework

Synthetic GPU cluster workloads generated with realistic job size distributions, arrival patterns, and resource constraints. Features extracted from cluster state snapshots.

Model Architecture

XGBoost regression predicting feasibility probability. Trained on 100K+ synthetic jobs with statistical validation (R² 0.937, MAE 0.058, RMSE 0.089).

Baseline Comparison

5 scheduler policies evaluated: FIFO, Shortest-Job-First, Priority Queue, Proactive (this work), and Neural Network baseline. Fair comparison on identical workload traces.

Fairness Constraints

Anti-starvation bumping policy: jobs waiting >3× their runtime are elevated. Gini index tracks fairness; measures prevent queue domination by large jobs.

Real-World Validation

LANL cluster traces (public dataset) validate generalization. Synthetic-trained model tested on real workload patterns with <2% performance delta.

Cost-Benefit Analysis

GPU-hour savings, energy consumption reduction, cloud cost avoidance, and user satisfaction impact quantified for 4-, 8-, 16-, 32-node clusters.
