======================================================================
PHASE 26: SCALING VALIDATION ANALYSIS
======================================================================

OBJECTIVE
----------------------------------------------------------------------
Validate that proactive scheduling scales gracefully from small (32 GPU)
to large clusters (256 GPU), without degrading model quality or
introducing prohibitive computational overhead.

SCALING POINTS TESTED
----------------------------------------------------------------------
  • Small      ( 32 GPUs,  4 nodes)
  • Medium     ( 64 GPUs,  8 nodes)
  • Large      (128 GPUs, 16 nodes)
  • XLarge     (256 GPUs, 32 nodes)


KEY METRICS ACROSS SCALES
----------------------------------------------------------------------
Cluster      Wait (ts)    Throughput     Latency (ms)   Overhead  
----------------------------------------------------------------------
Small           3743.83          10.4         15.18       1.52%
Medium          3481.65          17.9         15.49       1.55%
Large           2797.88          33.2         12.57       1.26%
XLarge          1794.49          59.2         10.24       1.02%


INFERENCE LATENCY: WHAT WAS MEASURED
----------------------------------------------------------------------
Points: 4
Range: 10.24 - 15.49 ms (1.5x spread)
Monotone in cluster size: NO

No complexity class is inferred from these numbers, and no
projection past the largest measured cluster is made.
inference_latency_ms is a wall-clock measurement: on a repeat
run of this repository the timing columns moved by up to 84%
while every non-timing column was bit-identical. Four noisy,
non-monotone points cannot identify a scaling law. Earlier
versions of this file fitted one anyway and reported
'O(1) / latency is CONSTANT' from a fitted exponent of -0.234,
then extrapolated that to 4,096 GPUs. The verdict and the
projections are withdrawn (v3.6).

SCHEDULING OVERHEAD
----------------------------------------------------------------------
Peak scheduling overhead: 1.55% of throughput
Worst inference latency: 15.49 ms (at 64 GPUs)
Both are wall-clock and machine-dependent.
